# v1.5.6 通知擷取驗證

## 修正範圍

- 監聽服務連線後補掃 Android 通知欄中的既有通知。
- 儲存監聽來源後立即掃描；服務未連線時主動要求 Android 重新連線。
- 取消只接收「對話／有聲通知」的限制，讓使用者選定 App 的靜音通知也能送入分析。
- 原生層與 App 同步「背景自動加入手機行事曆」設定。
- 點號時間、全形點號與時段範圍可在背景解析。

## 回歸案例

- `今天晚上7.30去星月廣場吃古拉爵`：判斷為當日 19:30。
- `晚上要不要打羽球` 接續 `6～8`：以同一對話內容判斷為當日 18:00–20:00。
- 儲存 LINE、Messenger 或 Instagram 後，通知欄內尚未清除的符合訊息會立即補抓。

## 驗證

- TypeScript 型別檢查通過。
- JavaScript／TypeScript 自動測試 71 項通過。
- Android 原生單元測試包含上述兩個實際訊息案例，並由發布工作流程在 APK 建置前執行。
