# v1.6.0 驗證範圍

## 自動化驗證

- TypeScript 型別檢查、Web 正式打包及 80 項規則測試。
- Android 原生單元測試包含分段訂位、嚴格背景寫入、廣告拒絕、相對日期及未讀數標題正規化。
- Google Play 使用的 APK 與 AAB 由相同 GitHub Actions 工作流程產生。

## 可靠性情境

1. AI 暫時斷線時，不會因第一則失敗而遺失已可由本機判定的行程。
2. AI key 遺失時不會偷偷關閉 AI；首頁顯示原因，未能安全判斷的通知保留。
3. 行程資料先持久化，再移除原生佇列並發出建立結果通知。
4. 佇列達上限時，優先淘汰最舊且訊號最低的普通聊天。
5. Android 通知服務未真正連線時不再顯示「運作中」，設定頁可重新連線及補掃。
6. 同一聊天標題由「林安玲」變成「林安玲（3 則新訊息）」時仍共用上下文。

## 平台限制

Android 只能讀取實際出現在系統通知中的文字。聊天 App 在聊天室開啟時若不產生通知，或通知預覽被系統隱藏，生活通知管家無法取得該段文字。
