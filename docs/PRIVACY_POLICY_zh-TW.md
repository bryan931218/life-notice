# 生活通知管家－隱私權政策

生效版本：1.2.0

生活通知管家提供「純本機模式」與可選的「AI 智慧辨識模式」。AI 功能預設關閉。

## Android 通知存取

只有在使用者主動到 Android 系統設定授權「通知存取」後，App 才能接收其他 App 顯示在系統通知欄的標題與文字。純本機模式只在裝置上以規則判斷日期、時間、期限與待辦訊號。使用者可隨時撤銷通知存取。

## AI 智慧辨識（選用）

開啟 AI 模式後，App 會將候選通知的來源 App 名稱、標題、文字、收到時間及必要的近期行程摘要傳送到 OpenAI API。模型可在受限制的工具集合中選擇：建立行事曆事件、建立待辦、更新既有事件、要求使用者確認，或忽略通知。

使用者手動選擇截圖時，AI 模式可將該截圖傳送到 OpenAI API，直接從圖片理解內容。若使用者不希望通知或圖片離開裝置，應保持 AI 模式關閉。

App 對 Responses API 使用 `store=false`。這不代表 OpenAI 絕不處理或暫時保留資料；OpenAI 仍可能依其 API 資料政策與濫用監控機制處理資料。正式公開版本將依實際部署與當時政策更新商店揭露。

## API key

私人測試版採 BYOK：使用者自行提供 OpenAI API key。key 透過作業系統安全儲存機制（Expo SecureStore）保存在裝置上，不寫入 App 原始碼、不提交 GitHub、不放入 JSON 備份，UI 也不回顯完整 key。使用者可隨時刪除 key，刪除後 AI 模式會自動關閉。

公開商店版不應把開發者共用 API key 直接包在行動 App 中；正式營運時應改採受控後端代理、配額與濫用防護。

## 本機資料與 OCR

行程、待辦、所選截圖、辨識結果、更正紀錄與 Android 通知偵測佇列保存在裝置 App 空間。AI 關閉時，手動截圖辨識使用 Android Google ML Kit 或 iOS Apple Vision 的裝置端 OCR。第三方系統元件或 SDK 仍可能依其政策傳送裝置、App、相容性或效能診斷資訊。

## Calendar 與提醒

所有候選事項先加入 App 內行程表。只有使用者另外開啟「自動同步到手機行事曆」並授權 Android Calendar 後，高信心且時間明確的事件才會自動寫入系統行事曆；低信心或有歧義者會要求確認。判斷仍可能出錯，重要時間請以原始訊息為準。

## iOS 限制

iOS 不允許第三方 App 任意讀取其他 App 的通知內容，因此 iPhone 版不提供 Android 式的跨 App 自動通知監看；可改用分享、貼上或截圖匯入。

## 備份、分享與刪除

JSON 備份不包含截圖附件或 API key。系統分享會把使用者選定的資料交給所選第三方 App。使用者可在設定刪除本機事項、附件、偵測佇列、API key 與排程提醒；已自行匯出或分享的副本需在對應位置另行刪除。

## 使用界線

本 App 不應作為醫療、緊急、安全關鍵或法律期限的唯一提醒。網路、勿擾、省電、通知權限、Calendar 權限及來源 App 的通知設定都可能影響功能。
