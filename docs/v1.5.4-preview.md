# 生活通知管家 1.5.4 測試版

此版本以 `v14-build` 的 v1.5.3 為基礎，直接提交建置使用的來源檔。保留 Gmail 誤判過濾、月曆、Maps 連結與快速回覆功能。

## 改善

- 監聽 App 管理：圖示、名稱搜尋、已選篩選、數量、權限狀態與未儲存確認。
- 設定分成監聽、提醒、AI 與行事曆、資料四組，按需展開。
- 提醒程度會保存並傳給原生監聽服務，讀取設定不再重設。
- 手動新增事件可預設不提醒、準時、提前 15／30／60 分鐘或 1 天。
- API key 驗證區分逾時、網路、金鑰、模型權限及限流錯誤；驗證失敗保留既有金鑰，儲存後另行啟用 AI。
- 完成事件與待辦按鈕改用完整動作名稱，編輯保留既有待辦完成狀態。
- 修正授權與已選 App 狀態混用，以及部分 Android 日期顯示回退到英文。

## 建置

Node.js 24、JDK 21、Android SDK 36。Windows 請使用較短的 ASCII 專案路徑，避免 C++ 建置路徑過長。

```sh
npm ci --ignore-scripts
npm run verify
npm run prebuild:android
cd android
./gradlew :app:assembleRelease -PreactNativeArchitectures=arm64-v8a,x86_64
```

APK 位於 `android/app/build/outputs/apk/release/app-release.apk`。此為測試簽章；Play 正式上架仍需正式簽章與商店審核。

GitHub workflow 直接建置當次提交，不再套用舊 migration 或由 workflow 回推程式碼。舊版最後一個回推步驟失敗，不代表該次 APK 建置失敗。推送 `v14-build`、`codex/listener-settings` 或手動執行，可產生 APK/AAB，並發布標示為 prerelease 的 APK。

## 驗證範圍

TypeScript 與 44 項既有測試通過。Android 36 模擬器檢查啟動、監聽搜尋與篩選、儲存／放棄變更及提醒設定保存。沒有接上實體手機，尚未驗證不同品牌的背景省電政策，也未用使用者的金鑰或真實聊天內容測試。

快速擷取是處理最近符合條件的通知；不會任意擷取其他 App 畫面。自動加入手機行事曆需權限與可寫入的行事曆，關閉同步不會刪除既有副本。
