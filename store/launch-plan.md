# 首發與收入設計

## 建議商業模式
第一版先免費取得真實使用資料與評價，不在尚未驗證留存率前硬上訂閱。驗證後採「免費核心 + Pro 一次買斷」：免費版保留手動事項、少量 OCR 與提醒；Pro 解鎖大量 OCR、進階整理規則、更多更正歷史與家庭模板。一次買斷可降低後端與客服負擔，符合低預算、低維護的被動收入方向。

第一個可測價格帶：NT$149–299 一次買斷。若後續加入跨裝置同步、多人即時協作等持續成本功能，再另外評估訂閱，不把雲端成本塞進一次買斷方案。

## 第一批獲客
優先鎖定「通知量高、但目前仍靠 LINE 截圖與腦袋記」的族群：大學生、家長、社區住戶與活動參與者。宣傳素材只示範一個非常具體的轉換：一張雜亂通知截圖 → 自動得到期限、準備清單、負責人與提醒。

低成本管道：Dcard 大學版／研究所版的實用工具分享、Threads 短示範、巴哈或相關社群的生活效率討論、Product Hunt / GitHub 作為開發故事與可信度補充。不要一開始買廣告，先看自然流量的安裝→首次匯入→7 日回訪。

## 首批要量的指標
- 安裝後 10 分鐘內是否完成第一次通知匯入。
- 第一次匯入後 7 天內是否再次新增通知。
- 每位活躍使用者每週整理幾則通知。
- OCR 後需要手動修正日期／標題的比例。
- 有多少人真的開啟提醒。
- 看到 Pro 價格頁後的購買率。

只有在「每週會重複用」成立後，才投入付費宣傳。
